# PromptBeast for Android

Native Android port of [PromptBeast](https://github.com/Haunt420/PromptBeast): prompt composer + Forge + Library for
the perchance.org generators (Mack's McGenerator is the paragon). Adults only. Credit: Mack (q1nerous1) for the
generator this is built around; all lists are re-authored.

* `:core` — pure Kotlin/JVM port of the desktop core. **Same seed, same prompt**: the Mersenne Twister and
  `random.Random` (int and str seeding, `getrandbits`, `randint`, `choices`) are bit-exact with CPython, and every
  module is verified against golden vectors generated by the Python reference (`tools/gen_golden.py` in the desktop repo).
* `:app` — Jetpack Compose UI (theme "Ember & Ink"): Compose, Forge, AI Tools, Mack, Library. Library files are interchangeable with the
  desktop (same JSON backup format, same content signatures).

No distribution work yet: CI builds a debug APK and attaches it to the run.

## Status (v0.1.0)

* Compose tab: eight boxes + negative + variables, model profile, sticky variables, a/an fix, roll 1-8 variants from a seed,
  live checks, copy / Mack key / share / keep.
* Forge tab: seeded character rolls from the built-in packs, per-slot lock / reroll / off, adult packs behind an 18+ gate
  (tier + heat), strict or loose coherence, send to Compose (replace / append / fill empty).
* Library tab: search, views (all / favourites / kept / history / archive), tags, title and note, load back into Compose,
  archive then delete for good. Settings: theme, JSON backup export / import, parity self-test.
* Mack tab: Mack's McGenerator in an embedded page (needs network; only perchance.org is loaded in the pane, any other
  link opens in your browser). **Fill** copies Compose into Mack's inputs, **Fill & generate** also presses Generate (it finds the button by label, aria-label, id or class in every frame; if it can't, it lists the buttons it saw under the header),
  **Pull** brings Mack's inputs back into Compose. The bridge script and the reply parser are ports of the desktop's and are
  checked against it (`mackbridge` suite); replies from the page are treated as untrusted (size / depth capped, strictly
  parsed). If the page can't load, Copy Mack key still works by hand.
* AI Tools tab: Enhance / Reshape / Variations / Doctor / Analyze-an-image, through any OpenAI-compatible endpoint you bring
  (key kept on the phone, out of backups) or by the manual copy-paste round trip. Every reply is cleaned and checked: minor-coded
  wording discards it, `{a|b}` braces and `[NAME]` variables are verified, and nothing is written to Compose until you Apply.
  The request builder, reply parser and provider helpers are ports of the desktop's, checked against it (`ai` suite).
* Your own packs: Forge → Your packs → Import pack (any `.pbpack`, up to 2 MB, UTF-8). Same format as the desktop; Copy template gives a
  commented starting point. They are validated like the built-in ones: unreadable files are refused, bad lines are dropped and
  listed under Notes, the age guard strips minor-coded tags, and 18+ packs stay hidden until Adult packs is on. A slot id that
  matches a built-in one adds your tags to it. Stored in the app's private files (`packs/`).
* The project autosaves; the library is SQLite with the desktop's schema.

Not yet: full desktop parity.

## CI

Three jobs on every push: `core` (the golden vectors on JDK 17), `android` (debug APK) and `emulator` (boots Android 14,
launches the real app, drives roll / keep / Forge / Library, and runs all 13 parity suites on the device's own runtime, drives the Mack pane and AI Tools against stand-in pages / a loopback endpoint;
screenshots come back as the `promptbeast-screenshots` artifact).

## Get the APK

Actions -> latest green run -> artifact `promptbeast-debug-apk`. It is a debug build: allow installs from unknown sources
once, then open the APK.

## Verify parity

    ./gradlew :core:test                 # replays ~1.7M checks against the Python vectors
    tools/kotlinc-local.sh test          # same suites, no Gradle downloads (uses a Gradle distribution's bundled kotlinc)

The app can also replay the vectors on the phone itself (Settings → Run parity self-test), which is the real check
for Android's regex/Unicode behaviour.

## Regenerating vectors (desktop repo)

    python tools/gen_golden.py ../promptbeastapk/core/src/test/resources/golden
    cp src/promptbeast/data/packs/*.pbpack ../promptbeastapk/core/src/main/resources/packs/

Vectors are byte-reproducible; a pack that drifts from the desktop's fails the `forge` suite.
